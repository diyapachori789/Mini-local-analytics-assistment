    ABOUT THIS WORKSPACE

    Local analytics, clear boundaries.

    Mini Local Analytics Assistant helps you explore synthetic Salesforce opportunity data using plain-English questions.

    How it works

    Submit one question at a time to receive a grounded answer, the returned result rows, and an optional locally rendered chart.

    Privacy

    CSV storage, DuckDB execution, SQL validation, result handling, and chart rendering are local. The configured Groq API receives the information required for SQL generation and answer phrasing.

    Session behavior

    Completed questions and their answers are saved on this machine in a local history database and kept until you delete them with “Clear saved history”. “Clear session” only clears what is on screen. The gallery links to chart images already on disk; if a chart file is removed the entry remains and is marked unavailable. History never runs a question again automatically and is never sent to the language model.

    Deliberately simple

    This is a single-user local workspace. It has no raw SQL interface, uploads, conversational memory, or multi-user support.
