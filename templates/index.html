ABOUT THIS WORKSPACE

Local analytics, clear boundaries.

Analytics Assistant helps you explore synthetic Salesforce opportunity data using plain-English questions.

How it works

Each message receives a grounded answer from the returned data. A chart is rendered locally when it would meaningfully improve the answer or when you ask for one.

Privacy

CSV storage, DuckDB execution, SQL validation, result handling, and chart rendering are local. The configured Groq API receives the information required for SQL generation and answer phrasing.

Saved chats

Chats are stored on this machine. Past result rows are not retained, so a reopened chat may show an answer without a data table. Saved chart files can also become unavailable if removed from disk.

Deliberately simple

This is a single-user local workspace. It has no raw SQL interface, uploads, schema browser, or multi-user support.

Delete every chat

Removes all saved chats from this machine. This cannot be undone.
